# 直徑控制器分析總結

對象：作用在拉速（Seed Lift SP）上的類 PID 直徑控制器。以下結論皆由 `rawdata` 的
clean BODY 段（38 段，>200 分鐘）實測驗證。

## 1. 控制律已對照實測 tag 驗證

| 定義 | 實測對應 | 吻合 |
| --- | --- | --- |
| `temp1 = (D_mean − D1mm)/6` | `D1mm` = D_mean 60s 前（10s 取樣→lag 6）| corr **0.997**, MAE 0.0007 |
| `dDmean` EWMA α=1/24 | 每 **5 s** 更新（10s 記錄 2 次）| MAE **0.0002** |
| `MV = K·Kc·(Er_M+Rate)` | 驅動 **Seed Lift SP** 的增量 | ΔSL≈1.15·MV, corr 0.67；cumsum(MV) vs SL corr 0.81 |

## 2. 只有 3 個獨立增益（K·Kc 不可分辨）

```
MV = Gp·Er_M + Gv·temp1 + Gd·dDmean
     Gp = K·Kc            = 0.0004    誤差—比例（經 SL 積分→實為誤差積分作用）
     Gv = K·Kc·Kr·2       = 0.16      變化率—微分
     Gd = K·Kc·Kr·(−1.33) = −0.1064   平滑率—阻尼
```

K 與 Kc 僅以乘積出現；Kr 與係數 2/−1.33 也耦合。**調 K、Kc、Kr 各自無意義**，
真正正交的旋鈕是 (Gp, Gv, Gd)。

## 3. 被控對象在此資料下不可辨識 → 不能仿真求最優

閉環、無外部激勵，拉速與擾動纏繞。ARX 辨識出的拉速→直徑增益：

| 尺度 | R² | 增益符號 |
| --- | --- | --- |
| 10s | 0.05 | **+3.0（錯）** |
| 60s | 0.38 | **+2.65（錯）** |

物理上拉快應變細（負增益），兩尺度符號都翻不過來 → 只能拿到反饋相關。
**任何據此仿真出的「最優增益」都不可信。** 要真最優需先做激勵實驗，
見 [excitation_experiment.md](excitation_experiment.md)。

## 4. 誤差是慢擾動、非 tuning 振盪

直徑誤差自相關（38 段）：負 lobe 深度中位數 **0.000**，**0% 晶棒有振盪特徵**。
自相關時間常數 ~13 分鐘。→ 回路**穩定、不欠阻尼**；那 ~1.1mm 誤差是慢速熱/液面
擾動漏過來的，不是控制器抖動。**方向性判斷**：既無振盪、tuning 偏保守，`Gp` 大概率
仍有上調空間以壓慢漂移（精確量需模型）。

## 5. Er_M 非線性有兩個真問題（不需模型即可修）

原始 Er_M 形狀：`|e|<1` 斜率 2；**`1<|e|<2` 平（增益死區）**；`|e|>=2` **跳到 ±3**。

- **死區佔運行 11.1%**：誤差從 1→2mm 時比例推力不增長 —— 正好在慢擾動需要加力時卡平。
- **e=±2 跳變 ±1.0**：誤差在 2mm 附近抖動→控制器 chatter（實測 2.4% 時間在此邊界）。

修正版（沙盒可切換）：`|e|<=1` 斜率 2、之後續以斜率 1 單調延伸，消去死區與跳變。
把靜態非線性改單調幾乎總是更安全，且**與被控對象模型無關**，可先落地。

## 6. 前饋空間有限

掃 14 個可觀測訊號對直徑誤差的領先互相關：只有 **temp29** 站在噪聲之上
（corr +0.197、領先 30s），其餘 <0.06。temp29 是唯一有點價值的前饋候選，但不強。
