# 多變量前兆預警模型 — 分析總結

目標：從 `precursor_windows`（133 特徵 × 145 視窗，86 case / 59 control、141 晶棒）
訓練斷線風險模型，看多變量能否勝過單一前兆標記。

## 方法

- **模型**：L2 正則化邏輯迴歸（Newton-IRLS，純 numpy，無 sklearn 相依）。
- **驗證**：**按晶棒分組** 5-fold 交叉驗證，取 out-of-fold 機率。4 根晶棒同時出現在
  case 與 control，分組可避免同晶棒洩漏。多 seed 平均以穩定。
- **標準化 / 補值**：都在訓練折內計算，不洩漏測試折。
- **基線**：單一最佳特徵的 AUC（`temp9::mean` ≈ 0.77）。

## 核心結論：多變量未超越單特徵

| λ | 訓練 AUC | OOF AUC |
| --- | --- | --- |
| 1 | 0.93 | 0.68（嚴重過擬合）|
| 10 | 0.90 | 0.74 |
| 100 | 0.87 | **0.76** |
| 500 | 0.86 | 0.74 |

**OOF AUC 最高約 0.76，並未超過單特徵基線 0.77。** 折內 top-k 特徵選擇也頂到 ~0.76。
原因是資料本身：n≈145 太小、133 特徵高度冗餘（同訊號的 mean/absmean 幾乎共線），
多加特徵引入的雜訊多過訊號。這**不是模型不夠力，是前兆訊號本質上低維、集中在少數標記**。

## 這頁因此提供什麼

不是炫模型，而是誠實 + 實用：

1. **過擬合曲線**：訓練 vs OOF AUC 隨 λ 背離，OOF 壓在單特徵基線之下——一眼看懂 p≫n。
2. **可調閾值操作點**：閾值 0.65 時精確率 85% / 召回 62% / F1 0.72，作為實際告警設定參考。
3. **風險分數**：每段 OOF 機率排行，可挑高風險段落回頭查逐點資料。
4. **特徵貢獻**：標準化係數 Top 15，主導者仍是 temp9 / D_ERR 系列，呼應單特徵結論。

## 延伸

要真正提升鑑別力，方向不是「加更多特徵」，而是：更多晶棒樣本（擴大 n）、
或引入時序動態（非單一視窗統計量），或針對特定相位（BODY 斷線）分開建模。
