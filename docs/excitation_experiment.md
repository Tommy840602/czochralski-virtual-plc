# 直徑控制增益優化 — 激勵實驗設計

## 為什麼需要這個實驗

現有資料是**閉環、無外部激勵**的：直徑控制器時刻在動，拉速（Seed Lift SP）完全被
直徑擾動「綁架」，兩者纏在一起。用這種資料做系統辨識，只會 recover 出反饋相關，
而非因果的「拉速 → 直徑」增益 —— 實測到的辨識增益在 10s 與 60s 兩個尺度**符號都是錯的**
（+3.0 / +2.65，物理上拉快應變細、應為負）。

**結論**：不做激勵，就無法建立可信的被控對象模型，也就無法用模擬求「最佳 Gp/Gv/Gd」。
本實驗的目的，就是在**受控、可接受風險**的前提下，替拉速→直徑通道注入足夠的外部激勵，
使閉環辨識變成 well-posed，之後模擬優化才成立。

## 原理：閉環 + 外部激勵 = 可辨識

在既有控制器輸出上疊加一段已知的外部擾動訊號 `r(t)`：

```
Seed Lift SP = 控制器輸出(MV 累積)  +  r(t)   ← 注入激勵
```

因為 `r(t)` 由我們產生、與製程擾動**獨立**，它打斷了拉速與擾動的纏繞，
辨識就能分離出真正的通道增益。這是控制界標準的「closed-loop identification with
external excitation」做法，不需要斷開控制器（不需開環，安全性高）。

## 激勵訊號規格

| 參數 | 建議值 | 理由 |
| --- | --- | --- |
| 訊號型式 | **PRBS**（偽隨機二元序列）或多正弦 | 頻譜寬、能量集中在關心頻段、幅度受限 |
| 幅度 | 起始 **±2~3% of Seed Lift SP**（≈ ±0.03~0.05 mm/min），逐步微調 | 需大到直徑可見反應、小到不報廢晶棒 |
| 切換週期（PRBS clock） | **60~120 s** | 匹配觀測到的通道反應時間（拉速→直徑滯後約 0~3 分鐘）；clock ≈ 上升時間的 1/2~1/3 |
| 序列長度 | 至少 **7 位元 PRBS**（127 clock）| 涵蓋數個時間常數、低頻解析足夠 |
| 單次總時長 | **30~60 分鐘** | 兼顧統計量與晶棒長度成本 |
| 記錄取樣 | 若 PLC 允許，測試期間提高到 **5 s**（內部本就 5s 更新） | 目前落地是 10s，提高可改善辨識 |

## 執行條件

- **相位**：等徑（BODY）中段，熱場已穩定；**避開** NECK/CROWN/SHOULDER 轉換、以及接近
  收尾（TAIL）。
- **爐台/晶棒數**：在 **3~5 根**不同爐台的晶棒上重複，以捕捉爐間差異與模型變異。
- **基線**：測試前後各留 10 分鐘無激勵區段，作為擾動基線比對。

## 安全護欄（Abort 條件）

- 直徑誤差 `|Diameter − Target|` 逾 **1.5 mm** → 立即停止激勵，交還純控制器。
- 出現任何結構事件前兆（縮頸/斷線相關告警）→ 中止。
- 建議先在**可承受風險的資格認證片（qualification run）**上做，勿用量產良品片。

## 實驗後的分析流程（本平台可承接）

1. 以「已知控制器 + 注入 `r(t)`」做閉環辨識，估計拉速→直徑的離散傳遞函數（ARX/BJ），
   並在留出晶棒上驗證多步預測（符號應為負、DC 增益物理合理）。
2. 用辨識模型建**閉環模擬器**，注入各晶棒的殘差擾動序列（replay 擾動、換控制器）。
3. 對 (Gp, Gv, Gd) 做網格 + 梯度優化，目標＝穩態直徑誤差 std 最小，約束＝
   增益裕度/相位裕度、拉速動作量、無振盪。
4. 輸出建議增益 + 預測改善幅度 **附信賴區間**（由跨晶棒驗證與模型不確定度給出）。

## 預期產出

拿到激勵資料後，即可把目前「控制調參沙盒」從**開環 replay**（只顯示 MV 指令差異）
升級為**閉環模擬**（預測改變增益後的直徑軌跡與 std），屆時才能給出有依據的
「最佳 Gp/Gv/Gd」。在此之前，可先落地不需模型的改善：**修正 Er_M 為單調**
（消去 1<|e|<2 死區與 ±2 跳變，見沙盒對比）。
